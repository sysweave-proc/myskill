# 笔记模板 · Source Reading Note

> 用法：只保留被 Pattern Profile 支持的章节。模板是**下限**（保证不丢东西），不是上限（不要求每篇都长这样）。

```markdown
# <主题>

> 核心问题：<一句话>

## 系统位置

System → Subsystem → Concern → Scenario → Path → Topic

（只做定位，不重复 Atlas 全文）

## 一句话模型

<在细节之前给出最小且准确的模型>

## 主视图

<按主导模式选择的那一个视图；没有降低认知负荷就不画图>

## 1. 核心对象

### <EntityName>

职责：
关键字段：
管理者：
生命周期：

## 2. 核心路径 / 行为

<Flow / Data Path / Concurrency 主线；分支与条件用文字说明>

## 3. 状态 / 生命周期

<真实迁移 + 迁移条件；不要只有字段名>

## 4. 约束

不变量：
协议 / 顺序：
所有权规则：
错误与清理：

## 5. 关键实现

<短而有目的的代码片段；每段必须承担：结构 / 分支 / 迁移 / 锁 / 所有权 / 清理 中的一种证据角色>

## 6. 源码导读

当前概念 → 当前符号 → 下一个符号 → 为什么继续

## 7. 关键结论

| 结论 | 类型 | 置信度 | 证据 |
|---|---|---|---|
|  | FACT / INFERENCE / INTERPRETATION | HIGH / MEDIUM / LOW |  |

## 8. 下一步阅读

（含 prerequisites / unlocks，便于形成学习路径）

## 待解问题

- [ ] <open_question>
```

## 交付前自检

```text
[ ] 系统位置存在，且与 Atlas 一致
[ ] 主导模式唯一，主视图与它匹配
[ ] 每条关键结论都有证据锚点
[ ] 无 UNVERIFIED 结论被当成 FACT 呈现
[ ] 图/文/代码 没有重复同一解释
[ ] 概念 → 关系 → 源码 可导航
[ ] 冲突被记录，没有被强行调和
```
