# Changelog

## 0.5.1 — Incremental repair release

### Added
- progressive execution gates: Scope → Orient → Minimum Model → Pattern → Trace → Represent → Validate;
- progressive depth policy L0–L3;
- Core Skill vs capability-extension boundary;
- merge-based/non-regression evolution policy;
- baseline capability inventory;
- package integrity regression test;
- restored general exploration policy from the earlier baseline.

### Preserved
- complete v0.4 architecture foundation and reconstruction method;
- canonical knowledge model and architecture/path/topic/source integration;
- diagram catalog and representation policy;
- traceability and validation policies;
- knowledge-source registry;
- evolution rules, anti-patterns, gold/failure cases, and regression policy;
- templates and examples.

### Corrective note

The previously packaged `v0.5` was built from a reduced file set and therefore dropped established capabilities. It is treated as a regression and is **not** the baseline for further evolution. This release is based on the full `v0.4` asset set instead.
