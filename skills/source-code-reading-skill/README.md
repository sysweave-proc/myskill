# source-code-reading-skill

面向大型 C/C++ 项目的「源码阅读知识建模」技能包 —— **七版演进 + 一个中文交付版**：v0.1 ~ v0.5.1 是同一场会话在六个时刻冻结的**原始产物**（不是从会话正文重建的），v0.6.0 是**增量合并件**，v0.6.0-zh 是它的**中文化交付版**。

## 这是什么

一套以 Agent Skill 形式交付的源码理解方法论。核心主张：不要直接写 Markdown 总结，而是先建一张**单一、可追溯的系统知识模型**，再把它投影成图、表、文档。

```
重建架构模型 → 追踪运行路径 → 规范知识图谱 → 识别主导理解模式
→ 选有证据支撑的表达方式 → 生成可导航的阅读文档 → 校验 → 从反馈中学习
```

**演进纪律**（v0.5.1 起固化为硬约束）：新版本默认必须是 merge，不是 rewrite；删任何东西都要留下 reason / replacement / regression evidence。v0.6.0 是它的第一次兑现 —— v0.5.1 的 50 个文件**一个没删**，只做 +9 新增 / 9 覆写。

## 目录

**一个版本一个目录，进去就能看全**：「这一版讨论了什么、包长什么样、原始 zip 在哪」都在同一个 `versions/vX.Y/` 里。

```
skills/source-code-reading-skill/
├── versions/
│   ├── v0.1/ ~ v0.6.0/     README.md（本版说明与已知缺陷）+ skill/（文件树）+ source.zip（权威字节）+ conversation/（讨论过程）
│   ├── v0.6.0-zh/          中文交付版：完整中文化 + 13 项交付修复与加固（61 文件，可用版）
│   │   └── …               另有 source-code-reading.skill（官方格式分发包）、original-delivery/（交付原件，仅作留证）
│   └── …
├── skill-ds/               非谱系产物：读后重写版，v0.6.0 的 cognitive_execution_source
├── docs/evolution-audit.md v0.1–v0.5 演进审计（v0.5.1 的立项依据）
└── README.md
```

- `skill/` 与 `source.zip` 是同一份内容的两种形态（解压 vs 压缩原件）。
- `conversation/` 收逐轮对话全文、分享页内嵌的完整会话对象与原始 HTML。v0.6.0 无 `conversation/`，其过程记在包内 `skill/MERGE_DECISION.md`。

## 已知问题

1. **各版 frontmatter 过不了当前官方校验器** —— 允许键已收紧为 `{name, description, license, allowed-tools, metadata}`，顶层 `version` 会被直接判非法，且**先于** description 检查。`v0.6.0-zh` 已修（`version` 移入 `metadata.version`）；v0.1–v0.6.0 原版**不回溯修改**，以保住冻结字节（v0.6.0 另有一处 post-freeze patch：`description: >-` → `|-`，故其 `skill/` 与 `source.zip` 不再逐字节一致）。
2. **v0.4 的行尾与其他版本不齐** —— 其文件以单个 `\n` 结尾；这是 v0.4 行数出现 2,662 与 2,697 两个口径的原因。
