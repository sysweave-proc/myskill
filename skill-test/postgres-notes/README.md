## 3. 两条主线为什么必须分开

| | 元组线 | 进程内存线 |
| --- | --- | --- |
| 关注单位 | 一段字节（及其表示） | 一个进程（及其内存与登记） |
| 跨进程吗 | **不跨**：跨进程共享的只有 Buffer 页，元组本身不迁移 | **跨**：共享内存是本条线的主角 |
| 交集 | 只在「元组头里的 `t_xmin`/`t_xmax` 让共享字节变成我的事务的元组」这一点上，与本库另一条线无重叠 |

## 4. 与相邻文档的边界

| 本库管什么 | 归谁管 |
| --- | --- |

| — | `tuple/01` 是一份**地图篇**，按上述边界本应属宏观侧；此处是用户确认保留在库内的**有意例外**，定位为「给地形篇当前置的地图」，不做模块级全景 |

## 5. 扩展方式

新增一篇时：

1. **定问题**——先写出本篇回答的具体问句（不是「XX 概述」）。
2. **归主线**——放进对应主线目录，篇号在**该目录内**连续（不跨目录连号）。
3. **登记**——写完后在该主线 `README.md` 的篇索引表加一行，填写「对应问题」。
4. **引用**——跨主线引用用相对链接 `../<主线>/<篇>.md`。
